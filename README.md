# Ukraine War Timeline (UWT)

Интерактивная веб-платформа с хронологией войны в Украине: карта + временная шкала с 24.02.2022. Выбор любой даты синхронно меняет линию фронта, зоны контроля, события, статистику, потери и графики; автовоспроизведение (0.25x–60x) анимирует развитие конфликта день за днём.

Ключевые принципы: **проверяемость каждого факта** (обязательные ссылки на источники; оценки разных источников никогда не сливаются в одно число), производительность (статическая пре-генерация данных, GPU-рендеринг WebGL), масштабируемая архитектура (см. `docs/`).

> ⚠️ **Демо-данные.** Репозиторий поставляется с генератором синтетического датасета (грубое кейфрейм-приближение реальных фаз войны; ключевые события — реальные). Данные непригодны для цитирования. Продакшен-режим предполагает ETL из реальных источников (ISW, ACLED, Oryx, DeepState) по архитектуре `docs/03`, `docs/06` — формат файлов идентичен.

## Быстрый старт

```bash
pnpm install
pnpm gen:data     # генерация демо-датасета (~90 с, 1407 дней → apps/web/public/data)
pnpm dev          # http://localhost:3000
```

Полный стек (БД + API, опционально для фронтенда):

```bash
docker compose -f infra/docker-compose.yml up -d   # PostGIS + Redis + MinIO
cp .env.example .env
pnpm build:api                                     # prisma generate + сборка NestJS
pnpm --filter @uwt/api dev                         # http://localhost:4000/api/v1
```

## Что реализовано

- **Карта** (MapLibre GL, WebGL): зоны контроля, линия фронта, слой изменений за день (занято/освобождено), события; плавная смена даты — кроссфейд зон + покадровая интерполяция линии фронта + пульсация диф-слоя; fallback-стиль при недоступной подложке; `prefers-reduced-motion`.
- **Timeline**: ±день/месяц/год, ползунок (перетаскивание — в грубом LOD), календарь, ввод даты, маркеры ключевых событий, автовоспроизведение 0.25x–60x с предзагрузкой окна дат и адаптивной детализацией.
- **Панель событий**: фильтры, уровни достоверности (подтверждено/сообщается/заявлено/оспаривается), ссылки на источники, фокус карты по клику.
- **Статистика дня**: площадь контроля и дельта, длина фронта, «что изменилось за день», потери личного состава и техники **колонками по источникам**.
- **Графики** (`/stats`): площадь контроля, длина фронта, потери (серии по источникам, диапазоны min–max), интенсивность событий; синхронизированы с датой, клик по графику меняет дату.
- **Поиск** (Ctrl/⌘+K): города, ключевые события, даты («июнь 2023», 06.06.2023).
- **UI**: тёмная/светлая тема (карта переключается синхронно), сохранение настроек, горячие клавиши (`?` — справка), URL-состояние (`/?d=2022-11-11`), мобильная компоновка.
- **API** (NestJS + Prisma + PostGIS): `/api/v1/days/:date`, `/events` (keyset-пагинация), `/losses/*` (только раздельные серии — параметра агрегации не существует), `/search`, `/sources`.
- **БД**: схема PostgreSQL/PostGIS (`packages/db`) — снапшоты+дельты геометрии, события с обязательными источниками, потери по источникам, функция `rebuild_control`.

## Структура монорепозитория

```
apps/web        Next.js 15 + React 19 + MapLibre + Zustand + React Query + Tailwind
apps/api        NestJS + Prisma (read-эндпоинты контракта docs/05)
apps/etl        генератор демо-датасета (в проде — импортёры ISW/ACLED/Oryx/DeepState)
packages/shared zod-контракты данных (единые для web/api/etl)
packages/geo    геоматематика: ресемплинг/интерполяция фронта, упрощение, площади
packages/db     Prisma schema + SQL-миграции PostGIS + сид источников
infra           docker-compose (PostGIS, Redis, MinIO)
docs            проектная документация (этапы 1–8)
```

## Команды

| Команда | Действие |
|---|---|
| `pnpm dev` | dev-сервер фронтенда |
| `pnpm gen:data` | демо-датасет (диапазон: `UWT_LAST_DATE=2022-06-30 pnpm gen:data`) |
| `pnpm build` | сборка shared+geo+web |
| `pnpm build:api` | prisma generate + сборка API |
| `pnpm test` / `pnpm typecheck` | тесты и типизация всех пакетов |

## Дорожная карта до продакшена

1. Импортёры реальных источников (DeepState GeoJSON, ISW, Oryx, официальные сводки) вместо `apps/etl/src/regions.ts` — контракт файлов уже совпадает.
2. PMTiles-подложка (self-hosted) вместо CARTO; OG-изображения на дату.
3. Публикация `/data` в объектное хранилище за CDN (immutable + manifest).
4. Аудит лицензий источников, полная страница методологии, i18n (UK/EN).
5. E2E-тесты Playwright, режим сравнения дат, guided-туры.

## Источники данных (приоритет)

ISW → ACLED → Oryx → DeepState (со сверкой) → официальные заявления сторон (отдельными колонками) → поимённые проекты (BBC/Mediazona, UALosses — подтверждённые случаи, нижняя граница).
