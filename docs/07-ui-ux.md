# Этап 7. Проектирование интерфейса

## 1. Макет главной страницы (desktop ≥ 1280px)

## 2. Адаптивность

| Брейкпоинт | Компоновка |
|------------|-----------|
| ≥1280 | как выше; ≥1920 — панели шире, плотность графиков выше |
| 768–1279 (планшет) | панели закрыты по умолчанию, открываются как оверлеи поверх карты (одна за раз) |
| <768 (мобильный) | карта + компактный Timeline; события и статистика — bottom-sheet с тремя положениями (peek / half / full); фильтры — полноэкранный лист |

Touch: pinch-zoom карты не конфликтует со свайпом bottom-sheet (разделение зон), ползунок таймлайна — увеличенная зона касания 44px.

## 3. Дизайн-система

- **Тема**: тёмная по умолчанию (аналитический стандарт), светлая — переключателем; хранится в `localStorage` + `prefers-color-scheme`; реализация — CSS-переменные + Tailwind (`data-theme`). Стиль карты меняется синхронно (light/dark JSON-стили).
- **Палитра данных** (semantic, работает в обеих темах):
  - зоны РФ — красный `#c93c3c` (заливка 25–35% opacity), контур плотнее;
  - «серая зона»/оспариваемое — штриховка нейтральным;
  - подконтрольное Украине — без заливки (фон карты) — карта не «кричит»;
  - диф: занято — пульс красного; освобождено — пульс жёлто-синего градиента;
  - confidence: confirmed — сплошной бейдж, reported — контурный, claimed — пунктир, disputed — предупреждающий с иконкой.
  - Все пары цветов проверяются на контраст WCAG AA и различимость при дейтеранопии (красный/зелёный не является единственным различителем — везде дублируется формой/штриховкой).
- **Типографика**: Inter (UI) + tabular-nums для чисел/дат (не прыгает таймер playback).
- **Анимации DOM** — Framer Motion (панели, листы, появление карточек); **анимации карты** — собственный rAF (этап 6). Всё уважает `prefers-reduced-motion`.

## 4. Ключевые компоненты

### Timeline (самый важный компонент)
- Трек с насечками месяцев/годов; зум-режимы трека (весь период ↔ год ↔ месяц) колесом/пинчем.
- Маркеры ключевых событий (`is_key_event`) — точки над треком, hover → тултип, клик → дата.
- Кнопки: ±день/±месяц/±год, play/pause, скорость (0.25–60x, меню), поле даты с маской + календарь (react-day-picker).
- Полоска буферизации (как у видеоплеера) — какие даты уже предзагружены.
- Drag ползунка: во время перетаскивания карта обновляется троттлированно (z0), на отпускание — полная детализация.

### EventsPanel
- Виртуализированный список (@tanstack/react-virtual), группировка: ключевые → по типам.
- Карточка: иконка типа, время, заголовок, confidence-бейдж, источники (фавиконки-ссылки), кнопка «показать на карте».
- Фильтры (тип, confidence, только с геопривязкой) — синхронизированы с картой и URL.

### DayStatsPanel
- Число дня войны («День 468»), площадь под контролем + Δ за день со стрелкой.
- Мини-таблица потерь: колонки = источники (никогда не одно число), строки = категории; переключатель РФ/Украина.
- Спарклайны 30 дней → клик ведёт на /stats с этим графиком.

### /stats (страница графиков)
- Recharts/visx: площадь контроля (лента времени), длина фронта, кумулятивные потери по источникам (мультисерии с легендой-переключателем), интенсивность событий (стековые столбцы по типам).
- Вертикальный курсор текущей даты на всех графиках; клик по графику меняет глобальную дату (синхронизация через dateStore).
- Brush-выбор диапазона; экспорт PNG/CSV каждого графика.

### Поиск (⌘K / Ctrl+K)
- Командная палитра: города/области (с иконкой типа), события, операции, даты («июнь 2023» → прыжок), действия («включить слой ударов»).
- Результаты сгруппированы, навигация клавиатурой.

## 5. Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| ← / → | ±1 день (с Shift — ±1 месяц, с Alt — ±1 год) |
| Space | play/pause |
| + / − | скорость playback |
| ⌘K / Ctrl+K | поиск |
| E / S | панель событий / статистики |
| L | легенда/слои |
| T | тема |
| Home / End | 24.02.2022 / последняя дата |
| ? | шпаргалка клавиш |

## 6. Состояния и UX-детали

- **Первый визит**: 3-шаговый коуч-марк (таймлайн → слои → playback), больше не показывается.
- **Загрузка**: скелетоны панелей; карта появляется с fade-in; никогда не блокируем взаимодействие спиннером на весь экран.
- **Предварительные данные**: последний день — жёлтый бейдж «предварительно, обновляется».
- **Ошибка загрузки дня**: тост + авторетрай + кнопка; таймлайн помечает недоступные даты.
- **Сохранение настроек**: тема, слои, свёрнутость панелей, скорость — `localStorage` (zustand persist).
- **Шаринг**: кнопка «поделиться» копирует URL текущего состояния; OG-превью с картой на дату.
- **Доступность**: полная клавиатурная навигация панелей; live-region объявляет смену даты; альтернатива карте — таблица событий (она и есть EventsPanel); контраст AA.

## Самопроверка этапа 7

- *Риск: перегруженность мобильного экрана* → решение bottom-sheet с peek-состоянием проверить на прототипе первым (неделя UI-фазы); если тесно — статистика уезжает на отдельный таб.
- *Синхронизация «графики ↔ дата ↔ карта»* может породить циклы обновлений → единственный источник истины `dateStore`, все компоненты только подписчики; изменение даты — только через один action.
- *Красная пульсация на дальтонизм*: продублирована штриховкой и подписью в легенде. ✔
- *Тултипы источников с фавиконками внешних сайтов* — не хотлинкуем (приватность/скорость): иконки источников — собственный спрайт.
- Улучшение по итогам проверки: drag таймлайна троттлируется до z0-геометрии — без этого перетаскивание через год истории повесит сеть (добавлено в спецификацию Timeline выше).
