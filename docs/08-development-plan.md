## Definition of Done (проектный уровень)

- Каждый факт в UI кликабелен до источника; ни одно число потерь не является слиянием источников.
- Смена даты: начало анимации < 300 мс (кэш) / < 1 с (холодная), playback 10x без пропуска кадров на MacBook Air / среднем Android.
- Все инварианты publish (этап 4 §4) покрыты интеграционными тестами.
- E2E (Playwright): сценарии «открыл→листает дни», «playback», «поиск→flyTo», «шаринг URL воспроизводит сцену».

## Самопроверка этапа 8

- *Почему ETL раньше фронтенда?* Карта без реальных данных — самообман: анимация и LOD тюнингуются только на настоящей геометрии DeepState. Спайки фазы 0 дают минимум данных ещё раньше. ✔
- *Слабое место: параллелизм* — фазы 1 и 2 частично параллелятся (разные роли), сводка сроков это уже учитывает; при одном исполнителе — последовательность и ~15 нед.
- *Backfill 1600+ дней в 4.2 — недооценённый объём?* Митигация: аномалия-детектор сокращает ручную выверку до ~5% дней; тестовые 3 месяца в фазе 1 калибруют реальную скорость заранее.
- Улучшение по итогам проверки: добавлена контрольная точка после каждой фазы с демонстрируемым результатом — проект можно показывать заказчику каждые 2–3 недели.
